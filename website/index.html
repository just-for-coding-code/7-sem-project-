DECENTRALIZED ARCHITECTURE

Built for resilient local communication

01 / DUAL-ROLE BLE

Zero-Pairing Auto-Mesh

Simultaneously runs a BLE GATT Server + Advertiser and BLE Scanner + GATT Client so nearby Android devices connect automatically without manual Bluetooth pairing.

02 / MULTI-HOP ROUTING

Store-and-Forward Relay

Deduplicates packet IDs, decrements TTL across up to 5 mesh hops, and replays buffered packets when new neighbors enter range.

03 / END-TO-END CRYPTO

ECDH + AES-256-GCM DMs

Private direct messages derive a shared secret using P-256 ECDH keys and encrypt with AES-256-GCM so relay hops cannot inspect private payloads.

04 / EPHEMERAL PRIVACY

One-Tap Panic Wipe

Zero accounts, phone numbers, or cloud sync. Use Panic Wipe or run /wipe to erase local Room logs and rotate to a fresh cryptographic identity.
